# Data: S1A (ala Halabi)

## Raw sequences

* `s1Ahalabi_1470_nosnakes.fasta`: Sequences reconstructed from the MSA file, procured from [pySCA data](https://github.com/ranganathanlab/pySCA-data)

## MSAs

MSAs are produced using [clustal-omega](https://www.ebi.ac.uk/jdispatcher/msa/clustalo?stype=protein&outfmt=fa) with fasta output format and are named in accordance with the input fasta file.

## Structures

* `3TGI.pdb`: S1A Rat Trypsin reference protein, as used in Halabi et al, and procured from [pySCA data](https://github.com/ranganathanlab/pySCA-data).
